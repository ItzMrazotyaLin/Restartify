# Restartify

[![Paper](https://img.shields.io/badge/server-Paper%20%2F%20Purpur-4A4A4A?style=flat-square&logo=papermc)](https://papermc.io)
[![Java](https://img.shields.io/badge/java-17%2B-ED8B00?style=flat-square&logo=openjdk&logoColor=white)](https://adoptium.net)
[![API](https://img.shields.io/badge/api-1.20%20--%2026.x%2B-4A4A4A?style=flat-square)](https://papermc.io)

Плагин для **плавного перезапуска сервера**: перед рестартом запускается обратный отсчёт с
настраиваемыми оповещениями в чат и BossBar на экране, а сам перезапуск выполняется нативным
методом ядра.

> [!CAUTION]
> Этот плагин всё еще находится на стадии тестирования, поэтому при работе могут возникать ошибки. Если вы столкнулись с багом, пожалуйста, сообщите о нем в [Issues](https://github.com/ItzMrazotyaLin/Restartify/issues)!

## Поддерживаемые версии

| Компонент | Версии |
|---|---|
| Серверные ядра | Paper / Purpur **1.20 – 26.x+** |
| Java (JDK) | **17+** (для сборки проекта) |
| `api-version` | `1.20` |

Плагин собран под Java 17 и использует только Adventure API, который уже входит в Paper,
поэтому дополнительных библиотек на сервер класть не нужно.

## Описание

Обычный рестарт на сервере обрывает игрокам игру без предупреждения. Restartify решает это:
администратор запускает `/reboot`, и все, кто онлайн, видят таймер обратного отсчёта — в чате
(по расписанию или через интервал) и в виде BossBar. По истечении времени плагин перезапускает
сервер. В любой момент отсчёт можно отменить, а игрок, вошедший на сервер уже во время
отсчёта, автоматически увидит активный BossBar.

## Основные возможности

- **BossBar с динамическим таймером.** Прогресс плавно идёт от `1.0` до `0.0`, цвет
  (`PINK`, `BLUE`, `RED`, `GREEN`, `YELLOW`, `PURPLE`, `WHITE`) и стиль (`SOLID`,
  `NOTCHED_6/10/12/20`) настраиваются. Игроку, зашедшему во время отсчёта, бар показывается
  автоматически; при выходе и отключении плагина бар корректно убирается.
- **Оповещения в чат с настраиваемыми интервалами.** Три режима: `INTERVAL` — каждые
  N секунд (60, 45, 30, 15 …), `SCHEDULE` — только на заданных секундах
  (60, 30, 15, 10, 5, 4, 3, 2, 1) и `OFF` — полностью тихо. Дополнительно флаг
  `chat.enabled: false` оставляет игрока только с BossBar.
- **MiniMessage и классические коды одновременно.** В любом тексте можно свободно смешивать
  `<red>`, `<bold>`, `<gradient:#ff0000:#0000ff>`, `<#RRGGBB>` и legacy-коды `&c`, `&l`,
  `&#RRGGBB` — плагин сам расставит закрывающие теги, а `&r` сбросит форматирование.
- **Оповещение администраторов.** Все, у кого есть право или статус OP, получают сообщение о
  том, **кто** запустил перезапуск (ник игрока или `Console`). Консоль видит его тоже.
- **Отмена в любой момент.** `/reboot cancel` останавливает отсчёт, убирает BossBar у всех и
  рассылает оповещение об отмене.
- **Живая перезагрузка конфигурации.** `/reboot reload` перечитывает оба файла, не прерывая
  уже идущий отсчёт — новые тексты применяются сразу.

## Команды и права

| Команда | Описание | Право |
|---|---|---|
| `/reboot` | Запустить таймер перезапуска | `restartify.admin` |
| `/reboot start` | То же, что `/reboot` (явная подкоманда) | `restartify.admin` |
| `/reboot cancel` | Отменить запущенный обратный отсчёт | `restartify.admin` |
| `/reboot reload` | Перечитать `config.yml` и `messages.yml` | `restartify.admin` |
| `/rb` | Алиас `/reboot` | `restartify.admin` |

Единственное право — `restartify.admin`, по умолчанию выдаётся только операторам (`default: op`).
Выдаётся, например, через LuckPerms: `/lp user <ник> permission set restartify.admin true`.

> **Важно:** команда `/restart` принадлежит ядру (`org.spigotmc.RestartCommand`) и намеренно
> **не перехватывается** плагином. Перехват приводил к зацикливанию рестарта. Используйте
> `/reboot` — он сам вызывает нативный `Bukkit.spigot().restart()`.

## Конфигурация

При первом запуске плагин создаёт папку `plugins/Restartify/` с двумя файлами.

### `config.yml` — поведение

| Ключ | Описание |
|---|---|
| `countdown.seconds` | Длительность отсчёта в секундах (минимум `1`). |
| `chat.enabled` | `false` — глушит сообщения отсчёта, оставляя только BossBar. Ответы на команды продолжают работать. |
| `announce.mode` | `INTERVAL`, `SCHEDULE` или `OFF`. |
| `announce.interval-seconds` | Период для режима `INTERVAL`. |
| `announce.seconds` | Список секунд для режима `SCHEDULE`. |
| `bossbar.enabled` | Показывать ли BossBar. |
| `bossbar.color` | Цвет бара. |
| `bossbar.overlay` | Стиль бара (`SOLID` = сплошная заливка). |
| `bossbar.darken-screen` | Затемнять экран, пока виден бар. |
| `restart.action` | `RESTART` — нативный `Bukkit.spigot().restart()`; `SHUTDOWN` — `Bukkit.shutdown()`. Если ядро не поддерживает рестарт, происходит автоматический откат на `SHUTDOWN`. |
| `restart.delay-ticks` | Задержка в тиках перед перезапуском (`20` = 1 секунда). |

### `messages.yml` — все тексты

Здесь лежат сообщения в чат и заголовок BossBar. Доступные плейсхолдеры:

| Плейсхолдер | Значение |
|---|---|
| `%sender%` | Кто запустил или отменил рестарт (ник игрока или `Console`). |
| `%time%` | Оставшееся время в формате `MM:SS` (или `H:MM:SS`). |
| `%seconds%` | Оставшееся время в секундах. |
| `%total%` | Длительность отсчёта в секундах. |
| `%progress%` | Сколько процентов отсчёта осталось. |
| `%error%` | Текст ошибки (только в `restart-fallback`). |

Ключи верхнего уровня: `prefix`, `no-permission`, `usage`, `started`, `announcement`,
`already-running`, `restarting`, `not-running`, `canceled`, `canceled-broadcast`,
`reload-success`, `reload-failed`, `restart-fallback`, а также секция `bossbar.title`.
Префикс добавляется только к сообщениям в чат и не влияет на BossBar
(отключается через `settings.prefix-enabled`).

## Сборка проекта

Нужен установленный JDK 17 или новее.

```bash
# Linux / macOS
./gradlew build

# Windows
gradlew.bat build
```

Готовые плагины появятся в `build/libs/`:

- `Restartify-<версия>.jar` — основной файл для загрузки на сервер;
- `Restartify-<версия>-shadow.jar` — тот же плагин (все зависимости помечены как
  `compileOnly` и поставляются сервером, поэтому релокация пакетов не применяется).
